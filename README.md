# 600MW 发电机组热力平衡项目

## 项目简介

本项目是一个600MW发电机组热力平衡计算与可视化平台，用于模拟和分析大型发电机组的热力系统运行状态。

## 技术栈

### 后端
- **框架**: FastAPI + Uvicorn
- **语言**: Python 3.10
- **数据库**: SQLAlchemy
- **工质属性**: IAPWS + CoolProp
- **任务队列**: Celery + Redis

### 前端
- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **UI组件**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router
- **图表**: ECharts

## 热力平衡计算流程

### 概述

本系统采用基于迭代的热力平衡求解算法，支持一次再热、多级回热抽汽的复杂热力系统计算。

### 求解流程

```
┌─────────────────────────────────────────────────────────────────┐
│                    热力平衡求解流程                              │
├─────────────────────────────────────────────────────────────────┤
│  1. 模型构建                                                    │
│     └── 从JSON数据构建元件列表和连接关系                         │
│                          ↓                                      │
│  2. 初始化                                                      │
│     └── 设置主蒸汽流量、给水温度/压力等初始条件                   │
│                          ↓                                      │
│  3. 迭代求解 (循环直到收敛)                                      │
│     ├── 正向计算                                                │
│     │     └── 凝汽器 → 凝结水泵 → 低压加热器 → 除氧器            │
│     │         → 给水泵 → 高压加热器 → 锅炉 → 汽轮机 → 发电机     │
│     ├── 回热系统热平衡计算                                      │
│     ├── 抽汽量更新                                              │
│     └── 收敛判断 (给水焓变化 < 0.01 kJ/kg)                      │
│                          ↓                                      │
│  4. 结果收集                                                    │
│     └── 收集所有元件的计算结果                                  │
│                          ↓                                      │
│  5. 系统性能计算                                                │
│     └── 计算发电功率、热效率、热耗率、煤耗率等                   │
└─────────────────────────────────────────────────────────────────┘
```

### 详细步骤说明

#### 1. 模型构建 (`_build_components`)

从前端传入的JSON模型数据构建元件实例：

```python
# 支持的元件类型
- boiler: 锅炉
- turbine: 汽轮机 (支持HP/IP/LP分级)
- condenser: 凝汽器
- heater: 加热器 (支持HP/LP/DA类型)
- pump: 水泵 (凝结水泵、给水泵)
- pipe: 管道
- generator: 发电机
```

#### 2. 初始化 (`_initialize`)

设置初始计算条件：
- **主蒸汽流量**: 默认 500 kg/s (约600MW机组)
- **给水温度**: 默认 275°C
- **给水压力**: 默认 28 MPa
- 根据压力和温度计算给水焓值和熵值

#### 3. 迭代求解 (`_iterate`)

采用阻尼迭代法求解回热系统热平衡：

**收敛判据**:
- 给水焓值变化 < 0.01 kJ/kg
- 最大迭代次数: 100次
- 阻尼因子: 0.5（防止迭代发散）

**正向计算顺序** (`_default_forward_calculation`)：

| 步骤 | 元件类型 | 说明 |
|------|----------|------|
| 1 | 凝汽器 | 计算排汽凝结 |
| 2 | 凝结水泵 | 提升凝结水压力 |
| 3 | 低压加热器 | 按压力从低到高排列 |
| 4 | 除氧器 | 给水除氧 |
| 5 | 给水泵 | 提升给水压力至锅炉压力 |
| 6 | 高压加热器 | 按压力从低到高排列 |
| 7 | 管道 | 压力损失和热损失计算 |
| 8 | 锅炉 | 主蒸汽和再热蒸汽产生 |
| 9 | 汽轮机 | 高/中/低压缸依次计算 |
| 10 | 发电机 | 将机械功转换为电能 |

#### 4. 元件计算逻辑

**汽轮机计算** (`_setup_turbine_inputs`)：
- 根据抽汽压力设置各级抽汽口
- 计算等熵膨胀过程
- 考虑等熵效率和机械效率
- 输出排汽参数和抽汽参数

**加热器计算** (`_setup_heater_inputs`)：
- 获取被加热水入口参数（从上一级加热器）
- 获取抽汽参数（从汽轮机对应抽汽口）
- 计算热平衡：抽汽放热量 = 给水吸热量
- 计算疏水流量和温度

**锅炉计算** (`_setup_boiler_inputs`)：
- 给水入口：来自最后一级高压加热器
- 再热蒸汽入口：来自高压缸排汽
- 计算锅炉热负荷和效率

**发电机计算** (`_setup_generator_inputs`)：
- 收集所有汽轮机的内功率
- 考虑发电机效率和机械效率
- 计算最终发电功率

#### 5. 系统性能指标计算 (`_calculate_system_performance`)

| 指标 | 计算公式 | 说明 |
|------|----------|------|
| **发电功率** | 发电机输出功率之和 | 单位: MW |
| **汽轮机内功率** | 各级汽轮机内功率之和 | 单位: MW |
| **锅炉热负荷** | 锅炉产生的总热量 | 单位: MW |
| **热耗率** | Q_boiler / W_electrical × 3600 | 单位: kJ/kWh |
| **全厂热效率** | W_electrical / Q_boiler | 无量纲 |
| **标准煤耗率** | 热耗率 / 29308 × 1000 | 单位: g/kWh |
| **汽耗率** | 主蒸汽流量 × 3600 / 发电功率 | 单位: kg/kWh |

#### 6. 收敛判定

```python
# 收敛条件
dh = abs(current_feedwater_h - prev_feedwater_h)
if dh < 0.01:  # kJ/kg
    converged = True
```

当给水焓值变化小于 0.01 kJ/kg 时认为收敛，此时系统达到热平衡状态。

### 工质属性计算

系统使用 IAPWS-IF97 标准计算水和蒸汽的热力学属性：

- **饱和温度/压力**: `saturation_temperature`, `saturation_properties`
- **焓值计算**: `pt_to_h` (压力-温度), `ph_to_t` (压力-焓)
- **熵值计算**: `pt_to_s` (压力-温度), `ph_to_s` (压力-焓)

### 连接关系处理

通过端口连接关系自动传递参数：

```python
# 连接格式示例
{
    "from": "锅炉.主蒸汽出口",
    "to": "高压缸.主蒸汽进口"
}
```

系统自动解析连接关系，从上游元件的出口获取参数作为下游元件的入口参数。

## 抽汽系统

### 抽汽级数

600MW机组典型配置：
- **高压缸抽汽**: 3级 (用于高压加热器)
- **中压缸抽汽**: 2级
- **低压缸抽汽**: 3级 (用于低压加热器)

### 抽汽参数计算

每级抽汽的流量根据加热器热平衡迭代确定：

1. 假设初始抽汽量
2. 计算加热器出口水温
3. 更新给水焓值
4. 迭代直到给水焓值收敛

### 疏水系统

加热器疏水采用逐级自流方式：
- 高压加热器 → 除氧器
- 低压加热器 → 凝汽器（或逐级自流至下一级）

## 技术特点

1. **模块化设计**: 每个元件独立计算，易于扩展
2. **迭代求解**: 支持复杂回热系统的精确计算
3. **工质属性**: 基于国际标准的高精度计算
4. **收敛保障**: 阻尼因子防止迭代发散
5. **灵活配置**: 支持不同机组参数的自定义配置
