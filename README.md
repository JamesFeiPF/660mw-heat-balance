# 600MW 发电机组热力平衡项目

## 项目简介

本项目是一个600MW发电机组热力平衡计算与可视化平台，用于模拟和分析大型发电机组的热力系统运行状态。

## 技术栈

### 后端
- **框架**: FastAPI + Uvicorn
- **语言**: Python 3.10
- **数据库**: SQLAlchemy
- **工质属性**: IAPWS + CoolProp
- **任务队列**: Celery + Redis

### 前端
- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **UI组件**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router
- **图表**: ECharts

## 热力平衡计算流程

### 概述

本系统采用**双层迭代架构**的热力平衡求解算法，遵循工业标准计算流程，支持一次再热、多级回热抽汽的复杂热力系统计算。

### 求解流程（工业标准）

```
┌─────────────────────────────────────────────────────────────────┐
│                    热力平衡求解流程                              │
├─────────────────────────────────────────────────────────────────┤
│  1. 模型构建                                                    │
│     └── JSON解析设备 + 拓扑连接关系                             │
│                          ↓                                      │
│  2. 边界初始化                                                  │
│     └── 主汽流量、初终参数、环境参数、设备设计端差               │
│                          ↓                                      │
│  3. 双层迭代求解 (循环直到收敛)                                  │
│     ├── 外层迭代: 汽轮机通流计算                                │
│     │     └── 锅炉 → 高压缸 → 中压缸 → 低压缸                   │
│     │         → 计算各级抽汽压力/焓/抽汽量                       │
│     │                          ↓                                │
│     └── 内层迭代: 加热器热平衡                                  │
│           └── 高加 → 除氧器 → 低加 (按压力从高到低)             │
│                          ↓                                      │
│  4. 多指标联合收敛判断                                          │
│     ├── 给水焓变化 < 0.01 kJ/kg                                │
│     ├── 抽汽量偏差 < 0.001                                      │
│     └── 功率偏差 < 0.1%                                        │
│                          ↓                                      │
│  5. 全设备工况结果归集                                          │
│                          ↓                                      │
│  6. 整机性能指标核算                                            │
│     └── 热耗、煤耗、厂用电、循环效率                            │
└─────────────────────────────────────────────────────────────────┘
```

### 详细步骤说明

#### 1. 模型构建 (`_build_components`)

从前端传入的JSON模型数据构建元件实例：

```python
# 支持的元件类型
- boiler: 锅炉
- turbine: 汽轮机 (支持HP/IP/LP分级)
- condenser: 凝汽器
- heater: 加热器 (支持HP/LP/DA类型)
- pump: 水泵 (凝结水泵、给水泵)
- pipe: 管道
- generator: 发电机
```

#### 2. 边界初始化 (`_initialize_boundary_conditions`)

设置初始计算条件：
- **主蒸汽流量**: 默认 500 kg/s (约600MW机组)，可从给水泵参数获取
- **给水焓**: 根据锅炉参数估算
- **环境参数**: 凝汽器背压、冷却水温等

#### 3. 双层迭代求解 (`_double_layer_iteration`)

采用**双层迭代架构**求解热力平衡：

##### 外层迭代：汽轮机全局功率平衡

**计算顺序**（从热源到冷端）：

| 步骤 | 元件类型 | 说明 |
|------|----------|------|
| 1 | 锅炉 | 主蒸汽和再热蒸汽产生 |
| 2 | 高压缸 | 按压力等级从高到低 |
| 3 | 中压缸 | 再热蒸汽膨胀做功 |
| 4 | 低压缸 | 排汽至凝汽器 |

**主要任务**：
- 计算汽轮机各级膨胀过程
- 确定各级抽汽压力和焓值
- 估算初始抽汽量

##### 内层迭代：加热器单体热平衡

**计算顺序**（按压力从高到低）：

| 步骤 | 元件类型 | 说明 |
|------|----------|------|
| 1 | 高压加热器 | 3级，加热给水至高温 |
| 2 | 除氧器 | 给水除氧 + 加热 |
| 3 | 低压加热器 | 4级，预热凝结水 |
| 4 | 凝汽器 | 排汽凝结 |
| 5 | 水泵 | 提升水压力 |

**主要任务**：
- 逐台计算加热器热平衡
- 更新给水/疏水流量和焓值
- 传递边界条件

#### 4. 多指标联合收敛判据

```python
# 收敛条件（全部满足）
1. 给水焓变化 < 0.01 kJ/kg        # 焓值精度
2. 抽汽量相对偏差 < 0.001         # 流量平衡
3. 机组功率偏差 < 0.1%            # 功率平衡
```

**收敛判定逻辑**：
- 给水焓变化：衡量回热系统热平衡
- 抽汽量偏差：衡量流量分配合理性
- 功率偏差：衡量汽轮机做功一致性

#### 5. 元件计算逻辑

**汽轮机计算** (`_setup_turbine_inputs`)：
- 从锅炉获取主蒸汽参数
- 计算等熵膨胀过程
- 考虑等熵效率和机械效率
- 输出排汽参数和各级抽汽参数

**加热器计算** (`_setup_heater_inputs`)：
- 获取被加热水入口参数（从上一级加热器）
- 获取抽汽参数（从汽轮机对应抽汽口）
- 计算热平衡：抽汽放热量 = 给水吸热量 + 散热损失
- 计算疏水流量和温度
- 考虑端差和疏水冷却端差

**锅炉计算** (`_setup_boiler_inputs`)：
- 给水入口：来自最后一级高压加热器
- 再热蒸汽入口：来自高压缸排汽
- 计算锅炉热负荷和效率
- 考虑主蒸汽参数和再热参数

**发电机计算** (`_setup_generator_inputs`)：
- 收集所有汽轮机的内功率
- 考虑机械效率 (η_mech = 0.995)
- 考虑发电机效率 (η_gen = 0.985)
- 计算最终发电功率

#### 6. 系统性能指标计算 (`_calculate_system_performance`)

| 指标 | 计算公式 | 说明 |
|------|----------|------|
| **发电功率** | Σ汽轮机内功率 × η_mech × η_gen | 单位: MW |
| **汽轮机内功率** | 各级汽轮机内功率之和 | 单位: MW |
| **锅炉热负荷** | 锅炉产生的总热量 | 单位: MW |
| **热耗率** | Q_boiler / W_electrical × 3600 | 单位: kJ/kWh |
| **全厂热效率** | W_electrical / Q_boiler | 无量纲 |
| **标准煤耗率** | 热耗率 / 29308 × 1000 | 单位: g/kWh |
| **汽耗率** | 主蒸汽流量 × 3600 / 发电功率 | 单位: kg/kWh |

### 技术特点

1. **工业标准流程**：从热源（锅炉）到冷端（凝汽器）的正向计算
2. **双层迭代架构**：外层汽轮机全局平衡，内层加热器单体平衡
3. **多指标收敛**：焓值、流量、功率联合校验，避免假收敛
4. **模块化设计**：每个元件独立计算，易于扩展和维护
5. **工质属性**：基于IAPWS-IF97标准的高精度计算
6. **连接关系自动解析**：通过端口连接自动传递参数

### 工质属性计算

系统使用 IAPWS-IF97 标准计算水和蒸汽的热力学属性：

- **饱和温度/压力**: `saturation_temperature`, `saturation_properties`
- **焓值计算**: `pt_to_h` (压力-温度), `ph_to_t` (压力-焓)
- **熵值计算**: `pt_to_s` (压力-温度), `ph_to_s` (压力-焓)

### 抽汽系统

#### 抽汽级数

600MW机组典型配置：
- **高压缸抽汽**: 3级 (用于高压加热器)
- **中压缸抽汽**: 2级 (1级至除氧器, 1级至低压加热器)
- **低压缸抽汽**: 4级 (用于低压加热器)

#### 抽汽参数计算

每级抽汽的流量根据加热器热平衡迭代确定：
1. 外层迭代：汽轮机计算抽汽压力和焓值
2. 内层迭代：加热器根据热负荷确定抽汽量
3. 收敛检查：验证抽汽量和功率平衡

#### 疏水系统

加热器疏水采用逐级自流方式：
- 高压加热器 → 除氧器
- 低压加热器 → 逐级自流至凝汽器

### 连接关系处理

通过端口连接关系自动传递参数：

```python
# 连接格式示例
{
    "from": "锅炉.主蒸汽出口",
    "to": "高压缸.主蒸汽进口"
}
```

系统自动解析连接关系，从上游元件的出口获取参数作为下游元件的入口参数。
