# 火力发电机组热平衡计算组件标准文档
## 文档说明
本文档定义火力发电机组热平衡计算系统的**全部标准组件**，包含每个组件的**设备设计参数（输入属性）**、**计算结果参数（输出属性）**、**输入/输出接口定义**。
适用于：Python后端迭代求解方程 + HTML前端可视化拖拽连线（工艺流程搭建）。

# 统一规范（开发用）
## 1. 介质通用属性（所有流体接口统一字段）
- 流量：t/h 或 Nm³/h
- 压力：MPa(a) 或 Pa
- 温度：℃
- 比焓：KJ/Kg 或 KJ/Nm³
- 干度：-（蒸汽专用）

## 2. 前端组件规范
- 每个组件一个独立图标
- 接口使用**输入管脚/输出管脚**区分
- 支持连线建立上下游关系
- 支持双击打开参数配置面板

## 3. 后端计算规范
- 所有组件继承统一基类
- 统一输入输出数据结构
- 支持迭代求解、热平衡闭合计算
- 支持边界条件锁定 + 自动求解
